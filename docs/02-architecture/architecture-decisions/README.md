# Architecture Decisions

This directory contains Architecture Decision Records (ADRs) that document significant architectural decisions made during the development of **myTenant Invoice**. ADRs provide context, rationale, and consequences for important technical choices.

Each ADR should follow a consistent template, typically including:

-   **Title**: A concise title that describes the decision.
-   **Status**: Proposed, Accepted, Rejected, Superseded.
-   **Context**: The forces and challenges that led to the decision.
-   **Decision**: The chosen solution.
-   **Consequences**: The implications (positive and negative) of the decision.
